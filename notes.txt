-------------------------------------------------------------------------

Command	    What it does
+---------+-----------------------------+
git push	Uploads your changes to GitHub
git pull	Downloads and merges GitHub changes
git fetch	Checks and downloads remote updates without merging

- PUSH = Send my code to GitHub.
- PULL = Bring GitHub code to my computer.
- FETCH = Check what changed on GitHub without merging.(git fetch --all)
